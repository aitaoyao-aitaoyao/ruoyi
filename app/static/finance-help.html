一、仪表盘

1.1 核心指标卡片（第一行）

卡片含义点击行为影响链路
总负债(含房贷) 全部未偿还债务金额 无(仅展示) 来源：贷款待还本金 + 信用卡未还账单 + 分期剩余 + 房贷剩余本金
修改任一项→此卡片自动刷新
总负债(不含房贷) 除房贷外的债务 无 同上，减去房贷部分
总资产 所有收入记录的总和 无 来源：Income表所有记录SUM
新增/编辑/删除收入→刷新
本月应付利息 本月需要支付的利息 点击弹出利息明细弹窗 来源：贷款利息(待还计划due_date在当月)+分期手续费(当月到期)+房贷月利息
联动：修改还款计划/分期/房贷→此卡片变化→V2生存线变化→V2利息消耗率变化
本月POS手续费 本月POS刷卡手续费合计 无 来源：PosSwipe表当月fee汇总
新增/编辑/删除POS记录→刷新
净资产 手头现金-总负债 无 来源：设置页手头现金 - 总负债
存钱/负债变化→净资产同步变
月预算执行率 当月支出÷月预算×100% 无 来源：设置页月预算 + 当月支出
设预算后新增支出→执行率实时更新
>100%红色警告

1.2 V2风险指标卡片（第二行）

卡片公式风险阈值操作影响链路
债务燃烧率 月利息 + 月POS手续费 - 月减少本金 ≤0🟢 0~1000🟡 >1000🔴 触发变化：标记还款→月减少本金↑→燃烧率↓
新增分期→月利息↑→燃烧率↑
新增POS→月手续费↑→燃烧率↑
生存线 月收入 - 月支出 - 月利息 >月收入10%🟢 0~10%🟡 <0🔴 触发变化：新增收入→生存线↑
新增支出→生存线↓
利息增加→生存线↓
向下影响：生存线变化→债务自由预期变化→风险评级变化
债务自由预期 总负债 ÷ 生存线 ≤24月🟢 24~60🟡 >60🔴 取决于：生存线和总负债
还债→总负债↓→自由月数↓
生存线变负→显示"无法还清"
现金流破裂预警 手头现金 ÷ |月缺口| ≥12月🟢 6~12🟡 <3🔴 取决于：设置页录入的手头现金
现金不足→破裂月数↓→风险评级中"现金流"维度恶化
现金流为正→显示"无破裂风险"
利息消耗率 月利息 ÷ 月收入 × 100% <15%🟢 15~30🟡 >30🔴 触发变化：利息增加或收入减少→消耗率↑
收入增加→消耗率↓
向下影响：风险评级"利息吞噬"维度

1.4 还款提醒 & 利息明细

还款提醒：未来7天内到期的待还计划 + 信用卡还款日。来源：RepaymentPlan(pending, due_date在7天内) + CreditCard(bill_day在7天内)

本月应付利息弹窗：点击本月应付利息卡片打开。逐项列出贷款利息、分期手续费、房贷利息。每项包含名称、人员、到期日、金额、备注。

新增借款 + 新增借款 创建Loan记录+自动生成RepaymentPlan
→ 仪表盘总负债↑ → V2总负债↑ → 风险评级恶化
→ 统计报告平台分布刷新
→ 快照表新增记录
编辑借款 编辑 修改金额/利率/期数等
→ 还款计划自动重新生成(regenerate-plan)
→ 仪表盘负债金额变化
→ 利息统计变化
→ 快照表变化
已还期数自动计算=当前年月-开始年月
还款计划 还款计划 打开还款计划列表弹窗
标记已还：将该期status改为paid，记录paid_date
→ 该贷款paid_periods↑ → 剩余期数↓
→ 仪表盘总负债↓ → V2债务燃烧率↓

→ 统计报告利息统计(按due_date归属)

四、信用卡管理

操作按钮影响链路
新增信用卡 + 新增信用卡 创建CreditCard记录
必须设置账单日和还款日
查看账单 查看账单 自动生成当期账单(如不存在)
账单金额=POS刷卡+信用卡消费自动汇总
全额还款 全额还 paid_amount=bill_amount, status=paid
→ 该卡负债清零 → 仪表盘总负债↓ → 信用卡负债卡片↓
→ V2生存线不变(还信用卡不影响收支)
→ 快照card_debt↓
最低还款 最低还 paid_amount=min_payment(账单金额×10%), status=partial
→ 该卡负债=账单金额-最低还款额
→ 剩余差额仍计入总负债
录入账单 录入 弹窗可修改：账单金额、实际还款、利息、手续费、账单周期日期、还款截止日
→ 修改账单金额→该卡负债变化→总负债变化
→ 修改利息→统计报告利息统计变化→V2利息消耗率变化
→ 修改还款日→还款提醒变化
撤销还款 撤销 paid_amount=0, status=unpaid
→ 恢复到未还状态→负债重新计入→总负债↑
编辑信息 编辑信息 修改额度、利率、账单日、还款日

五、POS刷卡

操作影响链路
新增刷卡 创建PosSwipe记录，手续费=金额×费率(自动)
→ 本月POS手续费↑
→ 信用卡当期账单金额↑(自动汇总)
→ V2债务燃烧率变化(手续费增加)
→ 统计报告POS手续费统计变化
☑ 退款 勾选后金额自动变负数，手续费清零
→ POS手续费本月统计减少
→ 信用卡账单金额相应扣减
→ 信用卡已用额度减少
编辑/删除 修改金额或费率→手续费重算→联动同上

操作影响链路

→ 仪表盘分期负债↑ → 总负债↑

关键联动规则

1. 收入/支出变化 → 生存线 → 债务自由 → 风险评级
2. 标记还款(贷款/分期) → 月减少本金↑ → 债务燃烧率↓ → 总负债↓
3. 信用卡全额还款 → 该卡负债清零 → 总负债↓ → 净资产↑
4. 录入手头现金 → 现金流破裂预警 → 净资产 → 风险评级
5. 修改账单利息 → 月利息→V2利息消耗率→统计报告利息统计
6. 修改POS手续费 → V2债务燃烧率(手续费) → 信用卡账单金额
7. 修改分期费率 → 每月手续费→月利息→利息统计
8. 设置月预算 → 仪表盘预算执行率
9. 删除任何债务记录 → 总负债↓ → 所有指标反向变化
10. 修改任何记录的月份(period_value/due_date) → 该月份所有统计重新计算
