数据模型关系

核心数据实体
实体 核心字段 说明
LoanPlatform name, icon, description 贷款平台 (银行/借呗/抖音等)
Loan amount, rate, rate_type, start_date, end_date, repay_method 借款记录（核心）
RepaymentPlan due_date, principal, interest, status 还款计划（系统自动生成）
PosSwipe amount, fee_rate, fee, swipe_date, bank_card POS刷卡记录
CreditCard bank, card_number, bill_date, due_date, limit 信用卡管理
Wealth type, amount, rate, start_date, end_date 定期存款/理财
FeeConfig fee_type, rate, description 费率配置（POS等）

前端视觉风格方向

选择你喜欢的金融主题风格

A

暗黑金融风

深色背景 + 渐变霓虹色图表 + 玻璃拟态卡片，类似 Bloomberg 终端/Coinbase 风格

B

专业浅色风

白色背景 + 蓝色金融主题 + 简洁专业，类似银行 App/支付宝理财页风格

C

暗色 + 数据可视化

暗色主题 + ECharts 图表 + 大屏数据看板感，强调图表和数字的可视化呈现
