产品定位：LightPress CMS

一个轻量级但"像真的"内容管理平台，专为测试学习设计

系统定位
定位 相当于一个精简版 WordPress 后台，模拟真实 CMS 的完整业务链路
用户 三种角色：作者（写文章、上传图片）、编辑（审核、退回、发布）、管理员（管用户、看数据）
核心流程 作者写文章 → 提交审核 → 编辑审核（通过/退回） → 发布 → 上线展示
技术架构一览
后端框架 FastAPI 0.95 自动生成 Swagger 文档
数据库 SQLite 零配置，文件即数据库
ORM SQLAlchemy 2.0 现代化 ORM，类型友好
前端 Vue 3 + Tailwind CSS CDN 引入，零构建
认证 JWT Token 真实 Token 机制
测试 pytest + httpx + Selenium 3 层测试体系
资源占用 < 50MB 内存 本地开发无压力
目录结构（按功能模块组织）
