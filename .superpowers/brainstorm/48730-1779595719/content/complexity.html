你想要的 CMS 有多"真实"？

功能越丰富，测试场景就越多。但不能太庞大导致你无法驾驭。选一个适合的深度：

A

精简但真实（推荐）

核心模块：文章管理、分类/标签、富文本编辑、媒体库、多角色权限（作者/编辑/管理员）、文章审核流程。

测试场景：~40 个接口，完整的工作流测试、权限边界、文件上传，前后端分离的 SPA 界面。

相当于一个简化版 WordPress 后台，够"真"但不过载。

B

最小可用

文章 CRUD + 分类 + 用户认证。~20 个接口，简单的前端页面。快速上手但练习场景有限。

C

全功能 CMS

以上全部 + 评论系统、站点配置、SEO 元数据、API Token 管理、数据统计仪表盘、多语言、自定义字段。

~60+ 接口，丰富但开发和维护成本高。
