数据模型设计（7 张表）

覆盖 CMS 核心业务，关系清晰，便于练习关联查询测试

核心模型关系图
User ──1:N──▶ Article ──N:1──▶ Category
  │              │
  │              └──N:N──▶ Tag (article_tags 关联表)
  │
  ├──1:N──▶ Media (上传的图片/文件)
  │
  └──N:N──▶ Role (user_roles 关联表)
               │
               └──N:N──▶ Permission (role_permissions)
User（用户）
id, username, email
full_name, avatar_url
hashed_password
is_active, is_superuser
created_at
Article（文章）
id, title, slug
content (正文富文本)
excerpt (摘要)
status: draft|pending|published|archived
category_id, author_id
published_at, created_at, updated_at
Category（分类）+ Tag（标签）
Category: id, name, slug, description
Tag: id, name, slug
article_tags: article_id, tag_id
Media（媒体资源）
id, filename, original_name
file_path, file_size, mime_type
uploader_id, created_at
Role（角色）+ Permission（权限）
Role: id, name, description
Permission: id, name, code
user_roles, role_permissions（多对多）
文章状态流转
draft ──提交审核──▶ pending ──审核通过──▶ published ▲ │ │ │ └──退回────▶ draft │ │ │ └──────────── 归档 ◀───────────────────────┘ ↓ archived
