API 接口设计（~38 个端点）

全部返回 JSON，统一使用 Bearer Token 认证。覆盖 RESTful CRUD、状态流转、筛选分页、文件上传

接口设计要点
  • 文章列表支持 ?status=draft&category_id=1&keyword=xxx&tag=python&page=1&size=20 多条件组合
  • 所有 POST/PATCH 请求带 Pydantic 校验，错误返回 422 + 详细字段信息
  • 权限控制三层：公开（无需登录）、登录、角色（作者/编辑/管理员）
  • 文件上传限制：图片 5MB，其他 10MB，白名单 MIME 类型
  • 所有列表接口支持 page/size 分页，返回 total 总数
